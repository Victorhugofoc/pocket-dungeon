# Dungeon Reign RPG

RPG de ação para PC feito em three.js, sem assets: um herói, mapas abertos procedurais, loot, relíquias e um chefe por zona. Protótipo 0.1.

```
npm install
npm run dev     # http://localhost:5173
npm test
```

Controles: WASD move, mouse mira, botão esquerdo ataca, botão direito usa a técnica, Espaço esquiva, F poção, I inventário, M mapa.

Design em `docs/design.md`; estado e próximos passos em `HANDOFF.md`.
